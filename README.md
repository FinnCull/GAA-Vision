# GAA Vision

GAA Vision is an ongoing C++ and OpenCV project for analysing recorded Gaelic
football and hurling matches.

The long-term aim is to detect and track players and match objects, identify
important match events, and generate useful performance statistics from video.

## Current Features

- Video loading and playback using OpenCV
- Frame-by-frame video processing
- Initial object-tracking functionality
- Modular C++ project structure
- CMake-based build configuration

## Planned Features

- Player detection and tracking
- Ball or sliotar tracking
- Goal and point detection
- Player movement and positional statistics
- Match-event logging
- Exportable match reports

## Technologies

- C++
- OpenCV
- CMake
- Git
